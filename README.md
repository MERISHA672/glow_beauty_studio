# Glow Beauty Studio 💄

Welcome to **Glow Beauty Studio**, a modern and elegant beauty salon website designed to showcase professional beauty services and provide customers with an easy way to connect with the salon.

## 🌸 About the Project

Glow Beauty Studio is a responsive website built to give a beauty business a professional online presence.

## ✨ Features

- Modern and responsive design
- Professional hair styling services
- Beauty service gallery
- About section
- Contact information
- WhatsApp contact link
- Google Maps location
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
glow-beauty-studio/
├── index.html
├── style.css
└── script.js
```

## 🎯 Project Purpose

This project demonstrates how web development can help small businesses establish an online presence and reach more customers.
